🏠 사이트 홈(안경사 국가시험 공부)

4. 근시·원시·난시·혼합난시 구분 방법

핵심 포인트

  1. 축 경선 = S, 90° 경선 = S + C. 둘의 부호로 근시성/원시성/혼합 판정.
  2. 축 범위: 직 180±30, 도 90±30, 사 그 외(마이너스 원주 기준).
  3. 플러스 원주는 먼저 변환: 새 S = S + C, 새 C = −C, 축 ± 90.
  4. SE가 0이어도 혼합난시는 흐리다.
이 페이지 차례
  1. 4.1 처방 표기 읽는 법
  2. 4.2 예시 처방 판별 표 (교육용 가상 값)
  3. 4.3 증상 비교 표
  4. 자가 점검 퀴즈
핵심: 따로 검사하지 않는다
  • 근시·원시·난시는 별개 검사로 찾는 것이 아니라, 하나의 통합 굴절검사(타각적+자각적)로 얻은 처방값(S, C, Ax)에서 '읽어내는' 것입니다.
  • AOA도 굴절검사를 '근시·원시·난시를 보정하는 데 필요한 렌즈 도수를 결정하는 검사'로 설명합니다.

4.1 처방 표기 읽는 법

표기의미읽는 법
R / L (OD / OS)오른눈 / 왼눈OU = 양안
S (SPH, 구면도수)모든 방향에 같은 굴절력− = 근시 교정, + = 원시 교정, 0.00(PL, 플라노) = 구면 이상 없음
C (CYL, 원주도수)특정 방향(경선)에만 작용하는 도수 = 난시 교정량한국 안경원은 주로 마이너스(−) 원주 표기. 크기가 클수록 난시가 큼
Ax (AXIS, 축)원주렌즈의 축 방향(0~180°)도수가 '없는' 방향. 원주 굴절력은 축과 90° 방향에 작용
ADD (가입도)근거리용으로 원용 도수에 더하는 플러스노안 교정. 항상 +로 표기
Prism / Base프리즘 양(Δ)과 기저 방향BI(안쪽)/BO(바깥)/BU(위)/BD(아래)
PD동공간거리(mm)원용/근용, 단안 PD

두 주경선 도수로 바꾸어 생각하기 (가장 확실한 판별법)

마이너스 원주 표기 S / C × Ax에서 두 주경선의 도수는 다음과 같습니다.

  • 축 방향 경선의 도수 = S
  • 축과 90° 방향 경선의 도수 = S + C
  • 두 값이 모두 0 이하(−) → 근시성 난시 (하나가 0이면 '단순', 둘 다 −이면 '복합(복성)')
  • 두 값이 모두 0 이상(+) → 원시성 난시 (하나가 0이면 '단순', 둘 다 +이면 '복합')
  • 두 값의 부호가 서로 다름(+와 −) → 혼합난시
  • C = 0 → 난시 없음: S가 −면 근시, +면 원시

난시 축에 따른 분류 (마이너스 원주 기준)

분류마이너스 원주 축 범위의미참고
직난시 (WTR, with-the-rule)180° ± 30° (0~30°, 150~180°)수직 경선의 굴절력이 더 강함젊은 층에 흔하다고 알려짐
도난시 (ATR, against-the-rule)90° ± 30° (60~120°)수평 경선의 굴절력이 더 강함나이가 들며 증가 경향
사난시 (oblique)31~59°, 121~149°주경선이 비스듬함적응이 상대적으로 어려울 수 있어 착용 테스트 중요

※ 플러스 원주 표기에서는 축이 90° 바뀌므로 판정 전 반드시 마이너스 표기로 변환합니다. 변환(전치) 공식: 새 S = S + C, 새 C = −C, 새 축 = 축 ± 90°. 예) +1.00 +2.00 × 90 → +3.00 −2.00 × 180.

4.3 증상 비교 표

구분먼 곳가까운 곳흔한 호소검사 시 특징
근시흐림상대적으로 잘 보임(벗으면)눈 찡그림, 칠판·자막 안 보임, 야간 운전 불편운무 시 플러스에 민감, 과마이너스 위험
원시(경도·젊은층)대체로 잘 보임피로·흐림 가능근거리 피로, 두통, 집중 저하조절로 숨겨져(잠복원시) 측정값이 작게 나올 수 있음
원시(고도·중년 이상)흐림 가능흐림원·근 모두 불편, 노안 증상 조기 발생플러스를 잘 받아들이는지 단계적 확인
난시흐림·번짐흐림·번짐글자 겹침, 빛 번짐, 눈 피로, 두통방향에 따라 선명도 다름(난시표), JCC 응답
혼합난시흐림흐림전반적 흐림, 구면만 바꿔서는 개선 적음구면등가가 작아도 원주 교정 시 크게 개선
노안(원용 교정되어 있으면) 잘 보임흐림, 멀리 떼어 봄폰 글씨 멀리 봄, 어두우면 더 불편근점 멀어짐, 조절력 감소

자가 점검 퀴즈 (4문항)

보기를 누르면 바로 정답과 해설이 나와요. 기록은 저장되지 않아요.

문제 1
S +1.00 C −2.00 × 180의 판정은?
💡 축 경선 +1.00, 90° 경선 −1.00 → 부호가 달라 혼합난시.
문제 2
마이너스 원주 축 90°는?
💡 90 ± 30° = 도난시(수평 경선이 더 강함).
문제 3
+1.00 +2.00 × 90을 마이너스 원주로 바꾸면?
💡 새 S = 1 + 2 = +3.00, 새 C = −2.00, 축 90 + 90 = 180.
문제 4
처방의 ADD는?
💡 ADD = 원용에 더하는 근용 + 도수, 항상 +.
