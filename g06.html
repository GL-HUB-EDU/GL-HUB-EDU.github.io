3. 검사 단계별 절차 ③ – 사위·양안시·처방 결정·심리적 배경 (3.11~3.14)

핵심 포인트

  1. 가림-안가림 = 사시 여부, 교대 가림 = 총 편위. 드러난 눈이 안쪽으로 → 외편위.
  2. 마독스: 선이 막대 댄 눈 쪽 = 내사위(비교차), 반대쪽 = 외사위(교차).
  3. 처방은 굴절값 + 생활 거리 + 증상 + 착용 테스트로 결정. 최종 확인은 시험테.
  4. '1번/2번/비슷함' 세 선택지, 중립 질문, 같은 제시 시간.

3.11 사위·사시 검사 (커버테스트, 마독스 등)

담당: 안경사

목적

  • 두 눈의 정렬 상태(사위·사시) 확인
  • 눈 피로·복시 호소의 원인 파악, 프리즘 고려 여부 판단
  • 사시·새로 생긴 복시 등 안과 의뢰 대상 선별

방법

  1. 가림-안가림 검사(cover-uncover): 고객이 원거리(이후 근거리) 작은 시표를 주시 → 한 눈을 가리면서 가리지 않은 눈이 움직이는지 관찰. 움직이면 사시(현성 편위). 반대 눈도 반복
  2. 교대 가림 검사(alternate cover): 가림판을 두 눈 사이로 1~2초 간격 번갈아 이동해 융합을 끊고, 가림판이 옮겨질 때 새로 드러나는 눈의 움직임 관찰 → 사위+사시의 총 편위
  3. 움직임 해석: 드러난 눈이 안쪽으로 움직임 → 원래 바깥쪽에 있었음 = 외(外)편위(exo) / 바깥쪽으로 움직임 → 내(內)편위(eso) / 아래로 움직임 → 위쪽 편위(hyper)
  4. 필요 시 프리즘 바를 대어 움직임이 없어지는 프리즘 양 측정(프리즘 가림 검사)
  5. 마독스 막대(Maddox rod): 한 눈(예: 오른눈) 앞에 마독스 막대, 반대 눈은 점광원을 봄 → 오른눈은 '선', 왼눈은 '점'을 보게 되어 융합이 깨짐. 수평 편위 측정 시 막대를 수평으로 두면 수직선이 보임. 선이 점을 지나면 정위, 막대를 댄 눈 쪽(같은 쪽)에 보이면 내사위(비교차), 반대쪽에 보이면 외사위(교차)
  6. 결과를 원/근 각각 방향(eso/exo/hyper)과 양(Δ)으로 기록

이론적 근거 (왜 이렇게 하는가)

  • 융합(fusion)이 있으면 잠재된 편위(사위)는 숨겨짐. 가림판은 융합을 끊어 숨은 편위를 드러냄.
  • 가림-안가림에서 가리지 않은 눈이 움직인다는 것은, 그 눈이 원래 시표를 보고 있지 않았다는 뜻(사시).
  • 마독스 막대는 원주 렌즈 다발로 점광원을 선으로 바꿔, 두 눈이 서로 다른 모양을 보게 함 → 뇌가 하나로 합치지 못해(해리) 사위 양이 드러남.
  • 사위는 대부분 정상 범위에서 증상이 없으나, 조절·폭주 이상과 함께 근거리 피로의 원인이 될 수 있음(AOA 조절·폭주 이상 지침).
주의
  • 사시의 진단·치료는 안과 영역입니다. 안경원에서는 굴절 교정과 안경 처방(프리즘 포함) 판단에 필요한 범위에서 확인하고, 사시가 의심되면 안과로 안내합니다.
  • 영국 College of Optometrists의 의뢰 긴급도 표(Annex 4)도 갑자기 생긴 복시·사시·안검하수·신경마비를 24시간 내 응급 의뢰 대상으로 분류합니다.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.12 양안시 기능 검사

담당: 안경사

목적

  • 두 눈이 함께 편안하게 작동하는지(폭주·융합·입체시) 평가
  • 근거리 피로·두통·글자 겹침 호소의 원인 파악

방법

  1. 폭주근점(NPC): 작은 시표를 코 쪽으로 천천히 가져오며 '두 개로 보이는 지점'(분리점)과, 다시 멀리하며 '하나로 합쳐지는 지점'(회복점) 측정. 눈이 바깥으로 빠지는 것도 관찰
  2. 융합여력(vergence ranges): 포롭터 회전 프리즘으로 BI/BO를 서서히 늘리며 흐림점/분리점/회복점 측정(근·원)
  3. 입체시: 편광 안경과 입체시 검사지로 입체 인지 확인
  4. 억제 검사(예: 워스 4점 검사): 적·녹 안경으로 보이는 점 개수로 융합/억제/복시 확인
  5. 고객 증상과 함께 해석(수치 단독으로 결론 내리지 않기)

이론적 근거 (왜 이렇게 하는가)

  • AOA 성인 지침은 연령·증상·예비검사 결과에 따라 안구 정렬·운동, 사위, 폭주 여력·용이성, 억제·입체시, 조절력·조절 용이성을 평가하도록 안내함.
  • Sheard 기준 등 처방 판단 규칙은 교과서마다 다르므로 매장 내 안경사 판단 기준을 문서화해 사용.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.13 처방 결정 및 착용 테스트

담당: 안경사

목적

  • 측정된 '굴절값'을 고객이 실제로 편하게 쓸 수 있는 '처방'으로 전환
  • 적응 문제를 사전에 발견

방법

  1. 최종 굴절값, 기존 안경 도수, 나이, 생활 거리, 증상을 종합
  2. 변화량이 큰 경우(특히 원주도수 증가·축 변화·첫 난시 교정) 단계적 처방 검토: 구면등가를 유지하며 원주를 일부만 넣는 방법 등
  3. 시험테에 처방 렌즈를 넣고(정점간거리·경사각·PD 맞춤) 원거리 → 근거리 → 매장 내 보행(바닥·계단·진열대 직선) 확인 5~10분
  4. 확인 질문: 선명함, 바닥 기울어짐·울렁임, 어지러움, 두 눈 편안함, 근거리 거리감
  5. 불편 시 원인별 조정(과마이너스 → 구면 +0.25D, 왜곡 → 원주 감량/축 확인, 근거리 불편 → ADD·근용 PD 조정)
  6. 최종 처방과 상담 내용(적응 기간 안내, 재방문 기준)을 기록

이론적 근거 (왜 이렇게 하는가)

  • AOA 지침: 굴절 결과만으로 처방이 결정되지 않으며 다른 검사 결과와 고객의 시각 요구를 함께 분석해 처방 여부와 양을 정한다.
  • 원주렌즈는 경선마다 배율이 달라(경선별 배율 차이) 공간이 기울거나 늘어나 보일 수 있음 → 특히 사난시·고도 원주·처음 교정 시 착용 테스트가 중요.
  • 포롭터는 렌즈가 눈에서 멀고 기울기가 없으므로, 실제 안경과 가까운 시험테에서 최종 확인.

3.14 자각적 굴절검사의 심리·정신물리학적 배경

자각적 검사는 '고객의 판단'이라는 측정 도구를 쓰는 검사입니다. 사람의 판단은 피로·기대·질문 방식에 따라 흔들리므로, 검사자는 이를 이해하고 검사 방법으로 오차를 줄여야 합니다.

현상/개념설명현장 대응
강제선택(forced choice)과 '같음' 응답정신물리학에서는 두 자극 중 하나를 고르게 해 미세한 차이를 판별함. 그러나 차이가 판별 한계(역치) 아래면 고객은 '찍게' 됨"1번, 2번, 혹은 비슷하다" 세 가지 선택지를 처음부터 알려 줌. '비슷하다'는 정답(종료점)일 수 있음을 안내
반응 편향(response bias)고객이 '더 진하고 작고 또렷한' 쪽(마이너스 추가 시 상이 작고 대비가 높아짐)을 선호하거나, 검사자를 기쁘게 하려고 '좋아졌다'고 답하는 경향'더 진하다'가 아니라 '더 많이 읽히는가'로 판단(MPMVA). 마이너스 추가 후에는 반드시 한 줄 더 읽는지 확인
순서·시간 효과먼저/나중에 본 렌즈, 더 오래 본 렌즈가 유리하게 판단될 수 있음1번과 2번 제시 시간 비슷하게(각 1~2초), 애매하면 순서를 바꿔 반복
유도 질문"이게 더 좋죠?"처럼 기대를 담은 질문은 답을 유도중립 질문: "어느 쪽이 더 선명한가요, 아니면 비슷한가요?"
피로·집중력 저하검사가 길어지면 판단 일관성이 떨어지고 '아무거나' 답함핵심 단계 우선, 응답이 흔들리면 잠시 휴식, 같은 단계 반복 횟수 제한
조절 개입젊은 고객은 마이너스를 추가해도 조절로 보상해 '똑같이 잘 보임' → 과마이너스로 끝나기 쉬움운무 후 플러스 쪽에서 접근, MPMVA·적록·양안균형으로 재확인
역치와 단계 크기0.25D 차이를 구분 못 하는 고객도 있음(동공 크기, 시력 수준, 원주가 낮을 때)응답이 불명확하면 0.50D 단계로 크게 비교한 뒤 좁혀 가기(bracketing)
기대·불안'도수가 올라가면 눈이 나빠진다'는 걱정이 응답에 영향검사 목적과 방법을 미리 설명해 불안을 낮춤
'1번이 좋아요, 2번이 좋아요?' 기법 – 표준 대사
  • 시작 전: "렌즈를 두 개씩 보여드릴게요. 더 선명한 쪽 번호를 말씀해 주시고, 차이가 없으면 '비슷하다'고 해 주세요. 정답은 없으니 편하게 답하시면 됩니다."
  • 제시: "1번…(1~2초) 2번…(1~2초). 어느 쪽이 더 선명한가요, 아니면 비슷한가요?"
  • 망설이면: "다시 한 번 보여드릴게요. 1번… 2번…" (순서를 바꿔 제시해도 좋음)
  • 과마이너스 방지: "글자가 더 진해 보이는 것 말고, 한 줄 아래 글자가 더 읽히나요?"
  • 적록: "빨간 쪽과 초록 쪽 중 글자가 어느 쪽이 더 검고 진하게 보이나요?"

문제 1
교대 가림에서 가림판을 옮길 때 드러난 눈이 안쪽(코 쪽)으로 움직였다.
💡 원래 바깥쪽에 있던 눈이 돌아오는 것 → 외편위(exo).
문제 2
오른눈에 마독스 막대, 빨간 선이 점의 오른쪽에 보인다.
💡 막대 댄 눈과 같은 쪽 = 비교차 = 내사위.
문제 3
워스 4점에서 빨간 점 2개만 보인다(오른눈 빨간 필터).
💡 빨간 필터의 오른눈만 보고 있으니 왼눈이 억제된 상태.
문제 4
자각 검사 중 바람직한 질문은?
💡 중립 질문과 '비슷함' 선택지로 반응 편향을 줄여요.
