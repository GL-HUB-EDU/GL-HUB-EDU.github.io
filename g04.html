3.1 문진 (Case history)

담당: 안경사 (문진표 배부·회수는 직원 가능)

목적

  • 방문 이유(주소)와 생활 시환경을 파악해 검사의 초점을 정함
  • 질환 의심 신호(red flag)를 조기에 발견해 안과 의뢰 여부 판단
  • 기대치(원하는 결과)와 이전 불편 경험 확인

방법

  1. 대기 중 문진표 작성 안내(직원) → 안경사가 문진표를 보며 구두로 보완 질문
  2. 주소: 언제부터, 어느 거리(원/중/근), 한쪽/양쪽, 지속/간헐, 악화 속도
  3. 안경·렌즈 사용력: 현재 안경 사용 기간, 콘택트렌즈 종류·착용 시간, 마지막 검사 시기
  4. 전신·눈 병력: 당뇨·고혈압 등, 안과 수술(라식·백내장 등), 녹내장·망막 질환 진단 여부, 복용 약물
  5. 가족력: 녹내장, 고도근시, 사시 등
  6. 생활환경: 직업, 하루 근거리/디지털 기기 사용 시간, 운전(야간 포함), 취미·운동
  7. 위험 신호 확인 질문(7장 참고): 갑자기 안 보임, 통증, 충혈, 번쩍임·날파리, 겹쳐 보임(새로 발생), 시야 가림
  8. 기록: 고객의 표현을 가능한 그대로 기록(예: '모니터 글씨가 오후에 번진다')

이론적 근거 (왜 이렇게 하는가)

  • AOA 성인 종합 검사 지침은 시각·안과·전신 병력, 복약, 직업·여가의 시각 요구를 문진의 필수 요소로 제시함.
  • 같은 굴절값이라도 생활 거리·용도에 따라 최적 처방이 달라짐 → 문진이 처방의 방향을 결정.
  • 급성 증상은 굴절 문제가 아닐 수 있음 → 굴절검사보다 의뢰가 우선.
주의
  • 6세 이하 아동의 안경·콘택트렌즈는 의사의 처방에 따라 조제·판매해야 합니다(시행령 별표1).
  • 위험 신호가 확인되면 검사를 무리하게 진행하지 말고 안과 진료를 우선 안내합니다.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.2 기존 안경 측정 (렌즈미터, Lensometry)

담당: 안경사

목적

  • 현재 사용 중인 처방(S·C·Ax·ADD·프리즘) 확인
  • 새 처방과의 변화량 비교 → 적응 난이도 예측
  • 광학중심·PD·누진 렌즈 설계(아이포인트) 확인

방법

  1. 렌즈미터 영점·접안렌즈(수동식) 시도 조정 확인
  2. 안경을 안경다리가 아래로 향하게 놓고 렌즈 뒷면을 렌즈 받침에 밀착, 오른쪽(R)부터 측정
  3. 광학중심에 맞춘 뒤 구면·원주·축 읽기(자동식은 화면 값 출력)
  4. 광학중심 점찍기 → 좌우 광학중심 간 거리로 안경 PD 확인, 수직 높이 차이 확인
  5. 프리즘이 들어 있으면 방향(BI/BO/BU/BD)과 양 기록
  6. 누진/이중초점: 원용 측정부와 근용 측정부에서 각각 측정 → 차이 = ADD. 누진은 숨김각인으로 설계 확인
  7. 측정값을 기록지 '기존 안경' 칸에 기록, 사용 기간 메모

🔗 렌즈미터 구조 그림은 6.3절에서 볼 수 있어요.

이론적 근거 (왜 이렇게 하는가)

  • 안경 처방은 '안경 기준'(렌즈 뒷면 정점 굴절력)으로 표기하므로 뒷면을 받침에 대고 측정해야 처방 표기와 일치.
  • 기존 도수는 고객이 '익숙한 기준점'이므로 큰 변화(특히 난시축·원주도수)는 적응 문제를 일으킬 수 있음.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.3 동공간거리(PD) 측정

담당: 안경사 (직원은 원장 지시에 따른 보조 측정까지만, 결과 반영은 안경사)

목적

  • 렌즈 광학중심을 동공 위치에 맞춰 원치 않는 프리즘 효과 방지
  • 포롭터·시험테를 고객 눈 위치에 맞춤

방법

  1. 고객과 같은 눈높이에서 마주 앉기, 측정 거리 설정(원용/근용)
  2. PD 측정기: 각막 반사점(동공 중심 근처 빛 반사)에 커서를 맞춰 단안 PD(R/L)와 합계 확인
  3. 자(PD 자) 방법: 검사자 왼눈 ↔ 고객 오른눈, 검사자 오른눈 ↔ 고객 왼눈을 번갈아 보며 측정
  4. 근용 PD: 근거리 설정(예: 40cm)에서 측정. 원용보다 작게 나오는 것이 정상
  5. 2회 이상 측정해 재현성 확인 후 기록

🔗 PD 측정기 그림은 6.8절에서 볼 수 있어요.

이론적 근거 (왜 이렇게 하는가)

  • 렌즈 중심에서 벗어난 위치로 보면 '프렌티스 법칙'에 따라 프리즘이 생김: 프리즘(Δ) = 편심거리(cm) × 도수(D). 예) −6.00D 렌즈에서 2mm(0.2cm) 벗어나면 1.2Δ → 고도수일수록 PD 정확도가 중요.
  • 좌우 얼굴이 비대칭인 경우가 많아 합계 PD보다 단안 PD가 조제에 더 정확.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.4 시력검사 (나안시력·교정시력)

담당: 안경사

목적

  • 현재 상태의 기준 시력 기록
  • 굴절검사 후 개선 확인 및 최대교정시력이 정상 범위에 도달하는지 확인(도달 못 하면 질환 의심)

방법

  1. 시력표 거리(예: 5m 또는 6m 규격, 프로젝터 보정 거리) 확인, 조명 일정하게
  2. 단안(R → L) → 양안 순서. 한쪽을 가릴 때 눈을 누르지 않도록 가림판 사용
  3. 나안시력 → 기존 안경 착용 시력 → (굴절검사 후) 최대교정시력
  4. 한 줄에서 과반을 읽으면 그 줄을 시력으로 기록하는 등 매장 기준을 통일하고 오독 개수 메모(예: 1.0-2)
  5. 근거리 시력(예: 40cm 근용시력표)도 측정
  6. 교정시력이 나오지 않으면 핀홀(바늘구멍) 시력 확인: 핀홀로 좋아지면 굴절 문제 가능성, 좋아지지 않으면 굴절 외 원인 의심 → 안과 의뢰 고려

🔗 시력표·거울 보정 그림은 6.7절에서 볼 수 있어요.

이론적 근거 (왜 이렇게 하는가)

  • 핀홀은 들어오는 빛을 가는 다발로 제한해 흐림원(blur circle)을 줄이므로, 굴절이상에 의한 흐림은 개선되지만 매질 혼탁·망막 문제에 의한 저하는 개선이 제한적.
  • AOA 지침: 시력은 단안·양안, 기존 교정 유무, 원·근거리에서 측정하고 필요 시 핀홀 시력을 측정.
  • 한국은 소수시력(1.0 등)을 흔히 쓰며, 1.0은 대략 6/6(20/20), logMAR 0.0에 해당.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.5 타각적 굴절검사 (Objective refraction)

타각적(객관적) 검사는 고객의 응답 없이 기계나 검사자의 관찰로 굴절 상태를 측정하는 검사입니다. 현행 시행령상 안경사가 할 수 있는 타각적 굴절검사는 약제를 사용하지 않는 검사 중 자동굴절검사기기를 이용한 검사로 한정됩니다. 검영법(레티노스코프)은 보건복지부가 의사 업무로 설명하고 있으므로, 안경원에서는 원리 이해용으로만 학습합니다.

3.5.1 자동굴절검사기(오토레프랙터/오토케라토미터)

담당: 안경사

목적

  • 자각적 검사의 시작값(출발점) 확보
  • 각막곡률(K값)과 각막난시 확인
  • 측정값 불안정 등 이상 징후 발견

방법

  1. 기기 위생(턱받침·이마받침 소독) 및 고객 자세: 턱·이마 밀착, 머리 기울지 않게
  2. "안쪽 그림(열기구·집 등)을 편하게 보세요. 일부러 초점 맞추려 하지 마세요" 안내
  3. 눈 깜빡임 후 측정, 동공 중심 정렬 확인
  4. 눈당 3회 이상 측정, 신뢰도 지수(기기 표시) 확인, 값이 크게 흔들리면 휴식·깜빡임 후 재측정
  5. S/C/Ax, K1/K2(곡률·축), 필요 시 동공 크기 기록

🔗 오토레프·케라토 구조 그림은 6.1·6.2절에서 볼 수 있어요.

이론적 근거 (왜 이렇게 하는가)

  • 자동굴절검사기는 내부 시표를 흐리게(운무) 보여 조절을 쉬게 하도록 설계되어 있으나, 기계를 가까이 본다는 인식 때문에 젊은 층·아동은 조절이 개입해 근시가 과대 측정되는 경향(기계 근시, instrument/proximal accommodation)이 알려져 있음 → 결과는 '참고값'이며 자각 검사로 확인.
  • 대한검안학회 자료도 자동굴절검사 결과는 참고 자료로 활용되며 조절력이 강한 아동에서 정확도가 떨어질 수 있다고 설명.
  • 각막난시(케라토)와 전체 난시(레프)가 다르면 수정체 난시 등 내부 난시가 기여하는 것. 두 값을 비교하면 난시 원인 이해에 도움.
주의
  • 오토레프 값을 그대로 처방하지 않습니다. 특히 젊은 근시는 과교정(과마이너스) 위험이 큽니다.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.5.2 [이론] 검영법(Retinoscopy)의 원리 – 안경원 수행 불가, 이해용

🔗 검영기 그림은 6.6절에서 볼 수 있어요.

검영법은 검사자가 레티노스코프로 빛줄기(streak)를 눈에 비추고 동공 안 반사광(reflex)의 움직임을 관찰해 굴절이상을 측정하는 방법입니다. 본질은 '환자의 원점을 검사자의 눈(관찰구) 위치로 옮기는 렌즈'를 찾는 것입니다.

관찰의미 (원점 위치)교정 방향
동행(with motion): 반사광이 빛줄기와 같은 방향으로 움직임원점이 검사자보다 뒤(멀리) 또는 눈 뒤쪽 — 정시, 원시, 작업거리보다 약한 근시플러스(+) 렌즈 추가
역행(against motion): 반대 방향으로 움직임원점이 환자와 검사자 사이 — 작업거리보다 강한 근시마이너스(−) 렌즈 추가
중화(neutral): 동공 전체가 한 번에 밝아지고 움직임 없음원점이 정확히 관찰구 위치이때의 렌즈 = 총 검영값(gross)
  • 중화에 가까워질수록 반사광이 더 밝고, 넓고, 빨라짐(멀면 어둡고 좁고 느림).
  • 작업거리 보정: 중화 시 원점은 무한원이 아니라 검사자 위치이므로, 작업거리의 디옵터(1/거리)를 빼야 원거리 처방이 됨. 67cm → 1.50D, 50cm → 2.00D. 예) 67cm에서 +4.00D로 중화 → 처방 +2.50D. 일부는 작업거리 렌즈(+1.50D)를 미리 넣고 마지막에 뺌.
  • 난시는 두 주경선을 각각 중화해 그 차이로 원주도수와 축을 구함.
  • 안경원 업무 범위 밖: 현행 시행령은 안경사의 타각적 굴절검사를 자동굴절검사기기 이용 검사로 한정합니다. 이 원리는 오토레프 결과 해석과 원점 개념 이해에 활용하십시오.
