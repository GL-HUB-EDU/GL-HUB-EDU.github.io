2. 기초 이론 – 눈의 구조, 굴절, 조절, 굴절이상

핵심 포인트

  1. D = 1 ÷ 초점거리(m). +는 모으고(원시·노안), −는 퍼뜨린다(근시).
  2. 근시는 초점이 망막 앞, 원시는 뒤, 난시는 두 초선. 교정렌즈는 원점을 무한원으로 옮긴다.
  3. 조절 개입 → 근시 과대·원시 과소 측정. SE = S + C/2.
  4. 고도수(±4 D 이상)는 정점간거리 영향: Fc = F ÷ (1 − dF).

2.1 눈의 구조와 굴절 관련 기능

구조위치·형태굴절·검사와의 관련성검사·상담 시 포인트
각막 (cornea)눈 앞쪽의 투명한 돔 모양 조직눈 전체 굴절력의 가장 큰 부분을 담당. 각막 곡률이 경선(방향)마다 다르면 각막난시가 생김오토케라토미터로 곡률(K값) 측정. 불규칙한 측정상(마이어 왜곡)·불안정한 값은 원추각막·건성안 등 의심 신호
눈물막 (tear film)각막 표면을 덮는 얇은 층매끄러운 광학면을 만들어 줌. 건조하면 시력이 깜빡일 때마다 변동자동굴절·각막곡률 값이 흔들리면 깜빡임 후 재측정
홍채·동공각막 뒤 색을 띠는 조직, 가운데 구멍이 동공동공 크기는 초점 깊이(피사계 심도)와 수차에 영향. 동공이 작으면 흐림이 덜 느껴짐밝은 조명에서는 작은 도수 차이를 덜 구분 → 검사실 조명 일정하게
수정체 (crystalline lens)홍채 뒤 볼록렌즈 모양두께(곡률)를 바꿔 초점을 조절. 나이가 들면 탄력이 줄어 노안. 혼탁해지면 백내장교정해도 시력이 안 나오면 수정체·망막 문제 가능성 → 안과 의뢰
모양체근 (ciliary muscle)수정체 주변을 둘러싼 고리 모양 근육수축하면 소대가 느슨해져 수정체가 두꺼워짐(=조절)근거리 작업 후 모양체근 긴장이 남아 있으면 근시가 과대 측정될 수 있음
소대 (zonules, 섬모소대)모양체와 수정체를 잇는 가는 섬유모양체근 이완 시 팽팽 → 수정체 얇아짐(원거리), 수축 시 느슨 → 두꺼워짐(근거리)—
유리체 (vitreous)수정체 뒤 젤 형태나이가 들며 액화·수축 → 비문증(날파리증) 원인이 될 수 있음새로 생긴 비문증·섬광은 망막 열공·박리 신호일 수 있어 안과 의뢰
망막·황반 (retina, macula)눈 안쪽 벽의 감각막. 중심부가 황반상이 맺히는 '스크린'. 황반이 선명한 중심시력 담당교정시력 저하, 사물이 휘어 보임(변시증)은 안과 의뢰
안축장 (axial length)각막에서 망막까지의 길이같은 굴절력이라도 안축이 길면 근시, 짧으면 원시(축성 굴절이상). 성장기 근시 진행은 주로 안축 증가와 관련안경원 장비로는 보통 측정하지 않음. 근시 진행 관리 상담은 안과로

2.2 굴절의 원리: 디옵터, 초점, 원점·근점

디옵터(D)

  • 렌즈의 굴절력 단위. 굴절력(D) = 1 ÷ 초점거리(m). 예) 초점거리 0.5m 렌즈 = 2.00D, 0.25m = 4.00D.
  • +(플러스) 렌즈: 볼록렌즈, 빛을 모음(수렴). 원시·노안 교정. −(마이너스) 렌즈: 오목렌즈, 빛을 퍼뜨림(발산). 근시 교정.
  • 안경 도수는 보통 0.25D 단위로 처방합니다. 0.25D는 대략 '시력표 한 줄 전후'의 차이로 체감되는 경우가 많습니다(개인차 큼).

정시와 비정시

  • 정시(正視): 조절을 쉬고 있을 때 먼 곳(무한원)에서 오는 평행광선이 망막에 정확히 초점을 맺는 눈.
  • 비정시(굴절이상): 초점이 망막 앞(근시) 또는 뒤(원시)에 맺히거나, 방향(경선)마다 초점이 달라 한 점에 모이지 않는(난시) 상태.
  • 원인 분류: 축성(안축장이 길거나 짧음) / 굴절성(각막·수정체 굴절력이 강하거나 약함).

원점(遠點)과 근점(近點)

개념정의공식·예시검사와의 연결
원점 (far point)조절을 완전히 쉰 상태에서 선명하게 보이는 가장 먼 점근시 −2.00D → 원점 = 1/2 = 0.5m(50cm). 그보다 먼 것은 흐림. 정시의 원점은 무한원. 원시의 원점은 '눈 뒤쪽'(허상)교정렌즈의 역할 = 원점을 무한원으로 옮기는 것. 검영법의 원리도 원점 위치 찾기
근점 (near point)최대로 조절했을 때 선명하게 보이는 가장 가까운 점정시이고 조절력 4D → 근점 = 1/4 = 25cm근점 측정(푸시업)으로 조절력 추정 → 노안 가입도 계산
조절력 (amplitude)원점과 근점 사이를 바꾸는 능력(디옵터)조절력 = (1/근점거리) − (1/원점거리). 교정된 눈에서는 ≈ 1/근점거리(m)나이에 따라 감소(5장 Hofstetter 공식)

구면등가와 정점간거리

  • 구면등가(SE) = 구면도수 + 원주도수/2. 예) S −2.00 C −1.00 → SE = −2.50D. 난시를 덜 넣거나 뺄 때 SE를 유지하면 '최소착란원'이 망막에 유지되어 선명도 손실이 적음.
  • 정점간거리(vertex distance): 렌즈 뒷면과 각막 사이 거리(일반적으로 약 12mm 내외로 가정). 고도수(대략 ±4.00D 이상)에서는 거리 변화가 실제 효과 도수에 영향. 각막면 환산 도수 Fc = F ÷ (1 − d×F) (d: 미터). 예) −8.00D를 12mm에서 → 각막면 약 −7.30D. 콘택트렌즈 도수 환산이나 시험테-안경테 정점간거리 차이를 고려할 때 사용.

🧪 직접 해 보기: 굴절이상과 교정렌즈 → 초점은 어디에?

개념 모형이에요(거리 비율은 실제와 다름). 잔여 굴절이상 = 굴절이상 − 렌즈. 음수면 초점이 망막 앞(근시 상태), 양수면 뒤(원시 상태). 원시 상태는 젊은 눈이 조절로 일부 보상할 수 있어요.

2.3 조절의 원리

가까운 물체에서 오는 빛은 퍼지면서(발산) 들어오므로, 눈은 굴절력을 늘려야 망막에 초점을 맞출 수 있습니다. 이 과정을 조절(accommodation)이라 하며, 일반적으로 다음과 같이 설명합니다(Helmholtz 이론).

상태모양체근소대수정체결과
먼 곳 볼 때 (조절 이완)이완팽팽하게 당김얇고 평평해짐굴절력 감소
가까운 곳 볼 때 (조절)수축느슨해짐탄성으로 두꺼워짐(특히 앞면)굴절력 증가
  • 근거리 삼중반응(near triad): 가까이 볼 때 조절 + 폭주(두 눈이 안쪽으로 모임) + 동공 축소가 함께 일어남. 그래서 조절 이상은 사위·눈 피로와 연결됨(조절성 폭주).
  • 조절은 두 눈에 같은 양으로 일어남(Hering의 동등 신경지배 법칙). → 양안균형 검사가 필요한 이유(3.10).
  • 검사 중 고객이 무의식적으로 조절하면 근시는 과대(−가 과하게), 원시는 과소 측정됨 → 운무법·최대 플러스 원칙·적록검사로 조절 개입을 줄임.
  • 노안은 나이가 들며 수정체 탄력이 줄어 조절력이 감소한 상태(질병이 아닌 생리적 변화). 근시·원시 여부와 무관하게 누구나 진행.

2.4 굴절이상과 노안: 정의·원인·위험요인

구분정의주요 원인알려진 위험요인·관련 요인전형적 증상
근시 (myopia)조절 휴식 시 평행광선이 망막 앞에 초점안축장 증가(축성)가 대부분, 각막·수정체 굴절력 과다(굴절성)부모의 근시(유전 소인), 장시간 근거리 작업, 실외활동 부족 등이 문헌에서 반복 보고됨. 고도근시는 망막 질환 위험과 관련되므로 정기 안과 검진 권고먼 곳 흐림, 눈 찡그림, 칠판·TV 가까이 봄
원시 (hyperopia)조절 휴식 시 초점이 망막 뒤안축장이 짧음(축성), 굴절력 부족소아는 생리적 원시가 흔하고 성장하며 감소하는 경향. 젊을수록 조절로 보상(잠복원시)근거리 피로·두통, 독서 시 흐림. 고도이면 먼 곳도 흐림. 아동은 내사시·약시와 관련될 수 있음
난시 (astigmatism)경선(방향)마다 굴절력이 달라 한 점에 초점이 맺히지 않음각막(대부분) 또는 수정체 곡률의 방향별 차이정난시(규칙난시): 두 주경선이 90°로 직교, 안경으로 교정 가능. 부정난시(불규칙난시): 주경선이 직교하지 않거나 불규칙(원추각막, 외상·수술 후 반흔, 각막 질환 등) → 안경으로 완전 교정 어려움, 안과 의뢰원·근 모두 흐림·겹침, 글자 번짐, 눈 피로, 두통
노안 (presbyopia)나이에 따른 조절력 감소로 근거리 초점이 어려운 상태수정체 경화·탄력 감소 등 노화나이(대개 40대 전후부터 자각). 원시는 더 일찍, 근시는 안경을 벗으면 늦게 느끼는 경향가까운 글씨를 멀리 떼어 봄, 어두운 곳에서 더 불편, 근거리 작업 후 피로
통계 인용 주의
  • 유병률·진행 속도 등 수치는 연구마다 다르므로 고객 상담 시 출처 없이 숫자를 말하지 않습니다. 근시 진행 억제 치료(약물 등)는 의료 영역이므로 '안과 상담'을 안내합니다.

문제 1
근시 눈에서 평행광선의 초점은?
💡 근시는 초점이 망막 앞 → 오목(−)렌즈로 교정.
문제 2

💡 D = 1 ÷ 0.25 = 4.00 D.
문제 3

💡 SE = S + C/2 = −2.00 + (−0.50) = −2.50 D.

💡 모양체근 수축 → 소대 느슨 → 수정체가 두꺼워져 굴절력 증가.
