3.6 자각적 굴절검사 개요 (Subjective refraction)

자각적(주관적) 굴절검사는 렌즈를 바꿔 보여주며 고객의 응답으로 가장 선명하고 편안한 도수를 찾는 검사입니다. 국제적으로 널리 쓰이는 표준 순서는 다음과 같습니다(Clinical Optics, Iowa 대학 교육자료 등).

  1. 단안 운무 → 구면 정밀화(MPMVA: 최고 시력을 주는 최대 플러스)
  2. 난시 축 → 난시 도수 정밀화(JCC) — 축을 먼저(도수가 틀려도 축은 찾을 수 있지만 반대는 어려움)
  3. 구면 재확인(MPMVA 2차, 적록검사) — 원주가 0.50D 이상 또는 축이 10° 이상 바뀐 경우 특히 필요
  4. 반대 눈 반복
  5. 양안균형(두 눈의 조절이 똑같이 이완된 상태 맞추기)
  6. 양안 최종 구면 조정 → 근용 가입도(노안) → 착용 테스트

시작값은 기존 안경 도수 또는 오토레프 값 중 적절한 것을 선택하고, 포롭터에 단안 PD·정점간거리·수평을 맞춘 뒤 시작합니다.

🔗 포롭터·시험테 그림은 6.4·6.5절에서 볼 수 있어요.

3.7 운무법(Fogging)과 구면 정밀화(MPMVA)

담당: 안경사

목적

  • 조절을 이완시킨 상태에서 원거리 구면도수를 결정
  • 과교정(과마이너스) 방지

방법

  1. 시작값에 +0.75D~+1.00D 정도 플러스 추가(운무) → 시력이 약 0.5~0.6(20/30~20/40) 수준으로 흐려졌는지 확인. 덜 흐려지면 +0.50D 더 추가
  2. 0.25D씩 플러스를 줄여(마이너스 방향) 가며 각 단계에서 시력 확인
  3. 더 이상 시력이 좋아지지 않는 지점에서 멈춤 = 최고 시력을 주는 최대 플러스(MPMVA)
  4. 마이너스를 0.25D 더했을 때 '글자가 작고 진해 보이기만' 하고 줄이 늘지 않으면 추가하지 않음

이론적 근거 (왜 이렇게 하는가)

  • 플러스 렌즈를 더하면 눈이 인위적으로 '근시 상태'가 됨. 이때 조절을 하면 오히려 더 흐려지므로 눈은 조절을 풀게 됨 → 조절이 쉰 상태에서 도수를 찾을 수 있음.
  • MPMVA는 조절이 이완된 상태에서 최소착란원을 망막에 두는 도수를 찾는 원리.
  • Iowa 대학 교육자료: 마이너스 0.25D 추가마다 대략 한 줄의 시력 향상이 기대되며, 시력 향상 없이 추가 마이너스를 주지 말 것.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.8 난시 검출: 난시표(방사선 시표)와 운무

담당: 안경사

목적

  • 난시 유무와 대략의 축 방향 파악(보조 방법)

방법

  1. 운무 상태(모든 선이 약간 흐린 상태)에서 방사선(시계 모양) 난시표 제시
  2. "가장 진하고 선명한 선이 몇 시 방향인가요?" 질문
  3. 마이너스 원주 사용 시 '30 법칙': 가장 진한 선의 양 끝 시각 중 작은 숫자 × 30 = 마이너스 원주 축 근사값. 예) 12–6시 선이 가장 진함 → 6×30 = 180° / 3–9시 선 → 3×30 = 90°. 난시표 디자인에 따라 다를 수 있으므로 매장 장비 설명서를 함께 확인
  4. 모든 선이 같게 보일 때까지 원주를 추가 → 이후 JCC로 정밀화

이론적 근거 (왜 이렇게 하는가)

  • 운무로 두 초선(앞초선·뒤초선)을 모두 망막 앞에 두면, 망막에 더 가까운 초선 방향의 선이 가장 진하게 보임 → 이를 이용해 축 방향을 추정.
  • Moran CORE 자료: 난시표 방법은 상대적으로 덜 쓰이고 JCC가 가장 일반적인 방법.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.9 크로스실린더(JCC)로 난시 축·도수 정밀화

담당: 안경사

목적

  • 난시 축을 먼저, 그다음 원주도수를 정밀하게 결정

방법

  1. 구면을 MPMVA로 맞춘 상태, 최고 시력보다 1~2줄 큰 둥근 시표(또는 점군 시표) 제시
  2. 축 정밀화: JCC의 손잡이(축)를 원주 축과 일치시킴 → JCC의 주경선이 원주 축에서 45° 떨어짐. "1번과 2번 중 어느 쪽이 더 선명한가요(혹은 같나요)?" 마이너스 원주 사용 시 고객이 고른 쪽의 빨간 점(−) 방향으로 축을 돌림(처음 15° 정도, 점점 5°까지 작게). 응답이 뒤집히면(왕복) 그 가운데가 축
  3. 도수 정밀화: JCC 주경선을 원주 축에 일치(빨간 점이 축과 평행 vs 흰 점이 평행). 빨간 점 평행이 선명하면 −0.25D 원주 추가, 흰 점 평행이 선명하면 −0.25D 원주 감소. 두 면이 같으면 종료
  4. 구면등가 유지: 원주를 −0.50D 바꿀 때마다 구면을 +0.25D(반대 방향) 보정
  5. 원주나 축이 크게 바뀌었으면 구면 재확인(MPMVA·적록)

이론적 근거 (왜 이렇게 하는가)

  • JCC(예: ±0.25D)는 한 경선에 +, 직각 경선에 −를 가진 렌즈로, 뒤집어도 구면등가는 0 → 최소착란원 위치는 그대로 두고 '흐림의 모양'만 바꾸어 비교하게 함.
  • 축이 틀린 경우 두 면을 대면 잔여 난시가 한쪽은 커지고 한쪽은 작아짐 → 더 선명한 쪽 방향으로 축을 움직이면 잔여 난시가 줄어듦.
  • 축 정밀화를 먼저 하는 이유: 축은 도수가 정확하지 않아도 찾을 수 있지만, 축이 틀리면 도수가 정확히 찾아지지 않음(Clinical Optics).
  • 구면등가 유지 이유: 원주 변경 시 최소착란원이 망막에서 벗어나지 않게 하여 비교가 공정해짐.
☑ 체크리스트 (실습 평가표로 사용 가능)

3.10 적록검사(Duochrome)와 양안균형(Binocular balance)

담당: 안경사

목적

  • 적록: 구면 최종 확인, 과교정·저교정 판별
  • 양안균형: 두 눈의 조절 이완 상태를 같게 맞춤

방법

  1. 적록검사: 단안으로 빨강·초록 바탕 글자 제시 → "어느 쪽 글자가 더 검고 진하게 보이나요?" (선명도가 아니라 '검은 정도'를 묻기)
  2. 초록이 진함 → +0.25D 추가 / 빨강이 진함 → −0.25D 추가 / 같으면 종료(같아지지 않으면 빨강이 약간 진한 마지막 단계로 끝내는 방식이 흔함). 암기: 'RAM-GAP(Red Add Minus, Green Add Plus)'
  3. 양안균형: 두 눈을 모두 뜬 상태에서 양안에 +0.75D 운무(시력 약 0.5~0.6 수준) → 프리즘 분리(예: 오른눈 3Δ BU, 왼눈 3Δ BD) 또는 교대 가림
  4. "위·아래 중 어느 쪽이 더 선명한가요?" → 더 선명한 눈에 +0.25D 추가, 같아질 때까지 반복. 같아지지 않으면 우세안이 약간 선명한 상태로 종료
  5. 프리즘 제거 후 양안 동시에 −0.25D씩 줄여 최고 양안시력(MPMVA)까지 → 최종 원용 처방

이론적 근거 (왜 이렇게 하는가)

  • 적록의 원리(종색수차): 짧은 파장(초록)은 긴 파장(빨강)보다 더 많이 굴절되어 눈 안에서 더 앞에 초점이 맺힘. 노란빛이 망막에 맺히도록 정확히 교정되면 초록(앞)과 빨강(뒤)이 망막에서 같은 정도로 흐려져 같은 진하기로 보임. 초록이 진하면 → 초점이 뒤쪽(저교정 원시/과교정 근시) → 플러스 추가.
  • 적록검사는 색 이름이 아니라 대비(진하기)를 비교하므로 색각 이상이 있어도 활용 가능하다고 흔히 설명됨(응답이 불확실하면 MPMVA 결과 우선).
  • 양안균형의 이유: 조절은 두 눈에 똑같은 양으로 일어나므로, 한 눈에 플러스가 더 남아 있으면 두 눈이 동시에 선명할 수 없음. 운무 상태로 우세안 효과를 줄이고 비교해야 비우세안의 과마이너스를 막을 수 있음(Iowa 자료).
  • 양안균형은 두 눈의 최대교정시력이 비슷할 때만 의미가 있음. 차이가 크면 각 눈의 MPMVA 값을 유지.

JCC 정밀화 순서는?
💡 축은 도수가 틀려도 찾을 수 있지만, 축이 틀리면 도수가 정확히 안 나와요.
